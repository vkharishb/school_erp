# AKSHARA SCHOOL Login Branding — V1.1.DEV.16

The login experience reads public display values from Vite environment variables:

```env
VITE_SCHOOL_NAME=AKSHARA SCHOOL
VITE_PRODUCT_NAME=School ERP
VITE_LOGIN_TAGLINE=Smart learning. Simple administration. Secure operations.
VITE_LOGIN_WELCOME=One secure workspace for students, teachers, fees, attendance and academics.
VITE_RELEASE_VERSION=V1.1.DEV.16
```

Provider attribution / `Powered by` is intentionally **not rendered in V1.1.DEV.16**. It can be introduced later after the provider name/branding is approved.

`VITE_*` values are browser-visible configuration. Never place passwords, database credentials, API private secrets or signing keys in frontend environment variables.

An approved School logo can be added later as a public asset. Until then the login uses a neutral education mark rather than inventing an official logo.
